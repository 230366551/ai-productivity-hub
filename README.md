AI Workplace Productivity Assistant
A modern, responsive web application designed to help professionals streamline daily workplace tasks using the power of Artificial Intelligence. This application combines multiple AI-powered tools into a unified dashboard to improve productivity, communication, and decision-making.

🚀 Project Overview
The AI Workplace Productivity Assistant is an all-in-one platform that automates common workplace tasks such as email drafting, meeting note summarization, task planning, and research. It provides a clean and intuitive dashboard interface, making it easy for users to access multiple tools in one place.
